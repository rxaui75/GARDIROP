# GARDIROP — Your Wardrobe. Smarter. 👗

**AI-Powered Smart Wardrobe & Personal Styling App**

🚧 **Work in Progress — Actively Under Development**

GARDIROP is a personal mobile application project designed to make wardrobe management and everyday outfit styling smarter, easier, and more personalized.

Built with Flutter and Firebase, GARDIROP aims to help users organize their clothing, discover outfit combinations, and receive AI-assisted styling recommendations based on their wardrobe and personal preferences.

## ✨ Key Features

- **Digital Wardrobe:** Organize clothing, accessories, and wardrobe items in one place.
- **AI Clothing Scan:** Analyze clothing images to assist with adding items to the wardrobe.
- **Quick Add:** Add clothing items through a predefined visual catalog.
- **Personalized Onboarding:** Explore style preferences and build a personal style profile.
- **Outfit Styling:** Create and explore outfit combinations using wardrobe items.
- **AI Styling Assistance:** Analyze outfit combinations and provide styling suggestions.
- **Saved Looks:** Keep favorite outfit combinations for future inspiration.
- **Multilingual Support:** English and Arabic localization.

*Features are at different stages of implementation and testing.*
